## 🛠️ Tools Used

- Arduino IDE
- Gxwork 2
- Node-RED
- MQTT broker

## 🎯 Project Objectives
- To develop an automated plant-growing system using ESP32 and IoT technology.
- To monitor important growing conditions, including temperature, humidity, light intensity, pH, and nutrient concentration (TDS).
- To transmit sensor data via MQTT and visualize real-time measurements on a Node-RED dashboard.
- To enable remote monitoring of plant-growing conditions through a web-based interface.
- To integrate hardware and software components to improve the convenience and efficiency of plant cultivation.

- Simulate a material-sorting process in an industrial environment.
- Explore automation concepts through a virtual factory simulation.
- Demonstrate the project through a video presentation.
